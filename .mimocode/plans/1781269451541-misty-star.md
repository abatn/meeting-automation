## Hauptproblem: Images nicht im containerd
Quelle: `kubernetes-deployment-workarounds.md` Workaround 7

## Lösung: Image-Import + LiveKit hinzufügen

### Schritt 1: Node-Name ermitteln
```bash
CLUSTER_NODE=$(kubectl get nodes -o jsonpath='{.items[0].metadata.name}')
```

### Schritt 2: Images bauen
```bash
docker build -t meeting-automation-frontend:latest -f frontend/Dockerfile frontend/
docker build -t meeting-automation-backend:latest -f backend/Dockerfile backend/
docker pull livekit/livekit-server:latest
docker pull livekit/egress:latest
```

### Schritt 3: Images in containerd importieren
```bash
docker save meeting-automation-frontend:latest | docker exec -i "$CLUSTER_NODE" ctr -n k8s.io images import -
docker save meeting-automation-backend:latest | docker exec -i "$CLUSTER_NODE" ctr -n k8s.io images import -
docker save livekit/livekit-server:latest | docker exec -i "$CLUSTER_NODE" ctr -n k8s.io images import -
docker save livekit/egress:latest | docker exec -i "$CLUSTER_NODE" ctr -n k8s.io images import -
```

### Schritt 4: LiveKit Deployen (NEU)
```bash
kubectl apply -f infrastructure/kubernetes/livekit-configmap.yaml
kubectl apply -f infrastructure/kubernetes/livekit-secrets.yaml
kubectl apply -f infrastructure/kubernetes/livekit-server-deployment.yaml
kubectl apply -f infrastructure/kubernetes/livekit-server-service.yaml
kubectl apply -f infrastructure/kubernetes/livekit-egress-deployment.yaml
kubectl apply -f infrastructure/kubernetes/livekit-egress-service.yaml
```

### Schritt 5: Alle Deployments neustarten
```bash
kubectl rollout restart deployment/frontend deployment/celery-worker deployment/celery-beat -n meeting-automation
```

### Schritt 6: Warten + Verifizieren
```bash
kubectl wait --for=condition=ready pod -l app=frontend -n meeting-automation --timeout=120s
kubectl wait --for=condition=ready pod -l app=celery-worker -n meeting-automation --timeout=60s
kubectl get pods -n meeting-automation
```

### Schritt 7: Port-Forward
```bash
kubectl port-forward deployment/frontend 3000:80 -n meeting-automation
kubectl port-forward deployment/backend 8000:8000 -n meeting-automation
```
