# MeetingRoom UX Professional Redesign Plan

**Status:** Draft  
**Date:** 2026-06-13  
**Goal:** Transform MeetingRoom into a professional business meeting experience with full LiveKit SDK integration

---

## Current State Analysis

### LiveKit SDK Components Used (3/20+)
- ✅ `LiveKitRoom` — Connection
- ✅ `RoomAudioRenderer` — Audio playback
- ✅ `useParticipants` — Participant list
- ✅ `useConnectionState` — Connection state

### LiveKit SDK Components NOT Used (Critical Gaps)
- ❌ `VideoTrack` / `ParticipantTile` — No video support
- ❌ `ControlBar` — No pre-built controls
- ❌ `DeviceSelect` — No microphone/camera selection
- ❌ `Chat` — No in-meeting chat
- ❌ `Reactions` — No emoji/smiles during meeting
- ❌ `ScreenShare` — No screen sharing
- ❌ `ConnectionQuality` — No quality indicators
- ❌ `MediaDeviceSelect` — No device management

### Current UX Issues
1. **No microphone mute/unmute** — Only recording start/stop
2. **No emoji/reactions** — Missing LiveKit Reactions SDK
3. **No device selection** — Users can't choose mic/camera
4. **No screen sharing** — Critical for business meetings
5. **No in-meeting chat** — No text communication during meeting
6. **No connection quality** — No visual feedback on connection health
7. **No participant tiles** — Just a list, no visual presence
8. **Hardcoded text** — Some strings not i18n translated
9. **Mobile responsiveness** — Limited consideration

---

## Proposed Architecture

### New Component Structure
```
MeetingRoom.tsx (Main Container)
├── MeetingHeader.tsx (Title, Duration, Status)
├── LiveKitMeetingRoom.tsx (LiveKit Integration)

```

## Implementation Plan

### Phase 1: Core Controls (Priority: HIGH)
**Files:** `MeetingRoom.tsx`, new `ControlBar.tsx`

1. **Add LiveKit ControlBar component**
   ```tsx
   import { ControlBar, DeviceSelect } from "@livekit/components-react";
   
   <ControlBar
     controls={{
       microphone: true,
       camera: false,  // Audio-only for now
       screenShare: false,
       chat: false,
       leave: true,
     }}
   />
   ```

2. **Add DeviceSelect for microphone**
   ```tsx
   <DeviceSelect kind="audioinput" />
   ```

3. **Add mute/unmute toggle**
   ```tsx
   import { useToggle } from "@livekit/components-react";
   const [isMuted, toggleMute] = useToggle(MicrophoneTrack);
   ```

### Phase 2: Reactions & Chat (Priority: HIGH)
**Files:** new `ReactionsBar.tsx`, `ChatPanel.tsx`

1. **Add LiveKit Reactions**
   ```tsx
   import { Reactions } from "@livekit/components-react";
   
   <Reactions
     reactions={[
       { emoji: "👍", label: "Thumbs Up" },
       { emoji: "👏", label: "Clap" },
       { emoji: "😊", label: "Smile" },
       { emoji: "❤️", label: "Love" },
       { emoji: "🎉", label: "Celebrate" },
     ]}
   />
   ```

2. **Add in-meeting Chat**
   ```tsx
   import { Chat } from "@livekit/components-react";
   
   <Chat
     channel="meeting-chat"
     onMessage={handleChatMessage}
   />
   ```

### Phase 3: Video & Screen Share (Priority: MEDIUM)
**Files:** `ParticipantGrid.tsx`, `ScreenShareView.tsx`

1. **Add Participant Tiles**
   ```tsx
   import { ParticipantTile, useParticipants } from "@livekit/components-react";
   
   const participants = useParticipants();
   <Grid container spacing={1}>
     {participants.map(p => (
       <Grid item xs={6} md={4}>
         <ParticipantTile participant={p} />
       </Grid>
     ))}
   </Grid>
   ```

2. **Add Screen Share**
   ```tsx
   import { ScreenShare } from "@livekit/components-react";
   
   <ScreenShare
     onScreenShareStarted={handleScreenShareStarted}
     onScreenShareStopped={handleScreenShareStopped}
   />
   ```

### Phase 4: Connection Quality (Priority: MEDIUM)
**Files:** new `ConnectionIndicator.tsx`

1. **Add Quality Indicators**
   ```tsx
   import { ConnectionQuality, useConnectionQuality } from "@livekit/components-react";
   
   const quality = useConnectionQuality();
   <Chip
     icon={<SignalIcon />}
     label={quality === ConnectionQuality.Excellent ? "Excellent" : 
            quality === ConnectionQuality.Good ? "Good" : "Poor"}
     color={quality === ConnectionQuality.Excellent ? "success" : 
            quality === ConnectionQuality.Good ? "warning" : "error"}
   />
   ```

### Phase 5: Mobile & RTL (Priority: MEDIUM)
**Files:** `MeetingRoom.tsx`, CSS

1. **Responsive Layout**
   - Stack columns on mobile (< 768px)
   - Full-width controls on mobile
   - Touch-friendly button sizes

2. **RTL Support**
   - Use existing `useRTL` hook
   - Mirror control bar layout
   - Adjust spacing for RTL
