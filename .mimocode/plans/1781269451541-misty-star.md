## Schritt 1: docker-compose.yml stoppen
```bash
docker compose down
```

## Schritt 2: Docker Desktop K8s aktivieren
- Docker Desktop → Settings → Kubernetes → "Enable Kubernetes"
- Warten bis `kubectl cluster-info` funktioniert

## Schritt 3: Fehlende K8s-Manifeste für LiveKit erstellen

### Dateien die NEU erstellt werden müssen:

| Datei | Inhalt |
|-------|--------|
| `infrastructure/kubernetes/livekit-configmap.yaml` | livekit.yaml + livekit-egress.yaml als ConfigMap |
| `infrastructure/kubernetes/livekit-secrets.yaml` | LIVEKIT_API_KEY, LIVEKIT_API_SECRET (SOPS) |
| `infrastructure/kubernetes/livekit-server-deployment.yaml` | LiveKit Server (1 Replica, Ports 7880/7881/7881-7890) |
| `infrastructure/kubernetes/livekit-egress-deployment.yaml` | LiveKit Egress (1 Replica, Port 7000) |
| `infrastructure/kubernetes/livekit-server-service.yaml` | ClusterIP + NodePort für Signaling |
| `infrastructure/kubernetes/livekit-egress-service.yaml` | ClusterIP für Health |

### LiveKit Server Deployment (Quelle: docker-compose.yml Zeile 296-325)
- Image: `livekit/livekit-server:latest`
- Ports: 7880 (Signaling), 7881 (TCP), 7881-7890 (UDP)
- Volumes: ConfigMap für `/etc/livekit.yaml`
- Env: LIVEKIT_API_KEY, LIVEKIT_API_SECRET aus Secret
- Entrypoint: `/opt/livekit/entrypoint.sh` (dynamic IP detection)

### LiveKit Egress Deployment (Quelle: docker-compose.yml Zeile 327-351)
- Image: `livekit/egress:latest`
- Ports: 7000 (Health)
- Volumes: ConfigMap für `/etc/livekit-egress/config.yaml`
- Env: LIVEKIT_API_KEY, LIVEKIT_API_SECRET, LIVEKIT_WS_URL
- Resources: 2Gi Memory

## Schritt 4: Secrets SOPS-verschlüsseln
```bash
export SOPS_AGE_KEY_FILE=~/.config/sops/age/keys.txt
sops -e -i infrastructure/kubernetes/livekit-secrets.yaml
```

## Schritt 5: Deploy-Reihenfolge
```bash
# 1. Namespace
kubectl apply -f infrastructure/kubernetes/namespace.yaml

# 2. Secrets (SOPS decrypt + apply)
for f in infrastructure/kubernetes/*-secrets.yaml; do
  sops -d "$f" | kubectl apply -f -
done

# 3. ConfigMaps
kubectl apply -f infrastructure/kubernetes/backend-config.yaml
kubectl apply -f infrastructure/kubernetes/livekit-configmap.yaml

# 4. Infrastructure StatefulSets
kubectl apply -f infrastructure/kubernetes/postgres-statefulset.yaml
kubectl apply -f infrastructure/kubernetes/redis-deployment.yaml
kubectl apply -f infrastructure/kubernetes/rabbitmq-statefulset.yaml
kubectl apply -f infrastructure/kubernetes/minio-statefulset.yaml
kubectl wait --for=condition=ready pod -l app=postgres -n meeting-automation --timeout=120s

# 5. Application Deployments
kubectl apply -f infrastructure/kubernetes/backend-deployment.yaml
kubectl apply -f infrastructure/kubernetes/celery-worker-deployment.yaml
kubectl apply -f infrastructure/kubernetes/celery-beat-deployment.yaml
kubectl apply -f infrastructure/kubernetes/frontend-deployment.yaml
kubectl apply -f infrastructure/kubernetes/n8n-deployment.yaml

# 6. LiveKit (NEU)
kubectl apply -f infrastructure/kubernetes/livekit-server-deployment.yaml
kubectl apply -f infrastructure/kubernetes/livekit-server-service.yaml
kubectl apply -f infrastructure/kubernetes/livekit-egress-deployment.yaml
kubectl apply -f infrastructure/kubernetes/livekit-egress-service.yaml

# 7. Ingress
kubectl apply -f infrastructure/kubernetes/traefik-*.yaml
```

## Schritt 6: Docker Images in K8s laden
```bash
# Backend + Frontend Images bauen
docker build -t meeting-automation-backend:latest ./backend
docker build -t meeting-automation-frontend:latest -f frontend/Dockerfile frontend/

# In containerd importieren
docker save meeting-automation-backend:latest | docker exec -i desktop-control-plane ctr -n k8s.io images import -
docker save meeting-automation-frontend:latest | docker exec -i desktop-control-plane ctr -n k8s.io images import -
```

## Schritt 7: Verifikation
```bash
kubectl get pods -n meeting-automation

kubectl port-forward deployment/frontend 3000:80 -n meeting-automation
kubectl port-forward deployment/backend 8000:8000 -n meeting-automation
```
