# Fix: StatefulSet YAMLs an Cluster-State angleichen (2026-07-02)

## Problem
ArgoCD Sync schlägt fehl weil Git-YAMLs nicht mit Cluster-State übereinstimmen.
K8s lehnt StatefulSet-Spec-Änderungen ab (immutable fields).

## Differenzen

### postgres-staging
| Feld | Git | Cluster |
|------|-----|---------|
| limits.memory | 512Mi | 256Mi |
| requests.memory | 256Mi | 64Mi |
| storageClassName | local-path | longhorn (immutable — ignorieren) |

### minio-staging
| Feld | Git | Cluster |
|------|-----|---------|
| image | RELEASE.2025-09-07 | RELEASE.2024-12-18 |
| CPU/Memory Resources | fehlen komplett | 500m/1Gi, requests: 200m/512Mi |

## Änderungen
| # | Datei | Änderung |
|---|-------|----------|
| 1 | `postgres-statefulset.yaml` | limits.memory: 512Mi→256Mi, requests.memory: 256Mi→64Mi |
| 2 | `minio-statefulset.yaml` | image: RELEASE.2025→RELEASE.2024, resources hinzufügen |
| 3 | ArgoCD ignoreDifferences | `/spec` für StatefulSet (bereits gesetzt) + volumeClaimTemplates hinzufügen |

## Verifikation
1. ArgoCD Sync: 0 SyncFailed (oder nur volumeClaimTemplate-Problem)
2. Alle Pods laufen
3. `argocd app sync` → Phase: Succeeded
