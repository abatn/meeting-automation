# Sprint 3: Storage + PostgreSQL HA + Backups

## Umfang
1. **Longhorn** — Distributed Block Storage (CNCF)
2. **CloudNativePG** — PostgreSQL HA Operator (CNCF)
3. **Velero** — Cluster Backups mit MinIO als S3-Ziel

## Reihenfolge
1. Longhorn installieren + als Default StorageClass setzen
2. Bestehende PVCs migrieren (local-path → Longhorn)
3. PostgreSQL Backup vor CNPG-Migration
4. CloudNativePG Operator installieren
5. PostgreSQL StatefulSet → CNPG Cluster migrieren
6. Velero installieren + Backup-Schedule erstellen
7. Verifikation

## Risiken
- Single-Node: HA-Vorteile begrenzt (kein Failover zwischen Nodes)
- CNPG-Migration: Datenverlust-Risiko (Backup vorher!)
- Longhorn: 3 zusätzliche Pods, ~300MB Memory
