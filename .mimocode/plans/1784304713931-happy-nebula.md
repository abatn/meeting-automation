## Verbleibende Probleme

### 1. Frontend + MinIO: ErrImagePull
**Ursache:** Images nicht im k3s Store (k3s-Reset hat sie gelöscht)
**Fix:**
- Frontend: `docker build ... | k3s ctr images import` (bereits gebaut, 1s Cache)
- MinIO: `docker pull minio/minio:latest | k3s ctr images import`
- Alternativ: In Deployment YAMLs `imagePullPolicy: IfNotPresent` setzen statt `Always`

### 2. Backend Init:Error
**Ursache:** `ConnectionRefusedError` auf CNPG (10.43.91.164:5432)
**Fix:** CNPG `meeting-db-1` läuft bereits. Service `meeting-db-rw` muss existieren. Prüfe:
```bash
kubectl get svc -n meeting-automation-staging meeting-db-rw
```
Falls nicht vorhanden → CNPG Operator muss den Service erstellen (kann dauern)

### 3. livekit-egress CrashLoopBackOff
**Ursache:** Redis nicht erreichbar (10.43.101.10:6379)
**Fix:** Nach Redis-Pod Restart (ContainerStatusUnknown → Running) wird egress automatisch reconnecten. `kubectl rollout restart deployment/livekit-egress-staging`
