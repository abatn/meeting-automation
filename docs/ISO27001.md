## 1. Information Security Management System (ISMS)

Das System adoptiert einen risikobasierten Ansatz zur Informationssicherheit gemäß ISO 27001:2022 Annex A Controls.

## 2. Implementierte Security Controls (Kategorie 1)

### 2.1 Authentifizierung und Anwendungssicherheit (A.5.17 / A.8.26)
- **JWT-Auth & RBAC**: Vollständige JWT-basierte Authentifizierung in FastAPI (5 Rollen: DG, Manager, Participant, System Admin, Tech Admin)
- **Session-Blacklisting**: Redis-basierte Token-Blacklist für sicheren Logout (verhindert Replay-Angriffe)
- **Input-Validierung**: Strikte Input-Validierung für jeden API-Call durch FastAPI und Pydantic

### 2.2 Datensicherheit & Kryptographie (A.8.24 / A.10)
- **Verschlüsselung at Rest**: SQLAlchemy `EncryptedType` (Fernet AES-128) verschlüsselt sensible Inhalte (PV-Daten, MFA-Secrets) auf Datenbankebene
- **Passwort-Hashing**: Sicheres Hashing via bcrypt
- **ENCRYPTION_KEY**: In K8s ConfigMap hinterlegt (korrekter Fernet-Key, verifiziert Phase 30)

### 2.3 Audit & Logging (ISO 27035 / A.12.4.1)
- **AuditMiddleware**: Speichert alle sicherheitsrelevanten Anfragen (POST/PUT/DELETE) inklusive Benutzer-ID, IP und Aktion in dedizierter `audit_logs` Tabelle
- **Session-Isolierung**: Audit-Logging verwendet dedizierte `AsyncSessionLocal()` Session — unabhängig von FastAPI's Request-Lifecycle
- **Fehlerbehandlung**: `db.rollback()` im except-Block verhindert "Session als FAILED markiert"
- **Sicheres Logging**: Anonyme oder veraltete Sessions werden als Metadaten (`stale_user_id`) erfasst

### 2.4 Informationsweitergabe (A.5.14)
- **n8n Webhook Security**: Backend verlangt von n8n den Header `X-Internal-API-Key` für Datenabrufe
- **n8n UI**: NodePort 31678, NetworkPolicy erlaubt nur Ingress auf Port 5678

### 2.5 Celery Tenant Isolation (A.5.15 / A.8.26)
- **Problem**: `_process_recording_pipeline()` queryte `Recording` nur nach `Recording.id`, ohne `client_id` Filter
- **Fix**: `client_id` Parameter zur Pipeline-Funktion hinzugefügt. Alle Queries filtern nach `Recording.id AND Recording.client_id`
- **Tests**: 3 Security-Tests bestehen (vorher `xfail`)
